# কেস ডায়েরি — অ্যাডভোকেটের ব্যক্তিগত অ্যান্ড্রয়েড অ্যাপ

পুরো অ্যাপ বাংলায়। ইন্টারনেট ছাড়াই চলে। সব তথ্য শুধু আপনার ফোনেই থাকে, কোথাও পাঠানো হয় না।

## অ্যাপে কী আছে

| ট্যাব | কাজ |
|---|---|
| **আজ** | আজকের তারিখের মামলা, আগামীকাল ও আগামী ৭ দিনের তালিকা, যে মামলার তারিখ পার হয়ে গেছে অথচ ফলাফল লেখা হয়নি সেগুলো |
| **মামলা** | সব মামলা; মামলা নং, পক্ষ, আদালত দিয়ে সার্চ; চলমান/নিষ্পত্তি ও ধরন (দেওয়ানী/ফৌজদারী/পারিবারিক) ফিল্টার |
| **মামলার পাতা** | পরবর্তী তারিখ, **পূর্ববর্তী তারিখ**, তারিখ ধরে ধরে ইতিহাস (হাজিরা + আদেশ + পরের তারিখ), ফি-র হিসাব, নোট |
| **মক্কেল** | মক্কেলের নাম, ফোন (এক ট্যাপে কল), তার সব মামলা ও বাকি ফি |
| **হিসাব** | মোট ধার্য / প্রাপ্ত / বাকি, কার কাছে কত বাকি |
| **আরও** | রিমাইন্ডারের সময়, ব্যাকআপ ও রিস্টোর |

- **রিমাইন্ডার:** তারিখের আগের দিন সন্ধ্যা ৮টায় এবং তারিখের দিন সকাল ৭টায় নোটিফিকেশন আসে (সময় বদলানো যায়)।
- **সাপ্তাহিক ছুটি:** পরবর্তী তারিখ শুক্র/শনিবারে পড়লে সতর্ক করে।
- **ব্যাকআপ:** এক ট্যাপে ফাইল তৈরি হয়, Gmail / Drive / WhatsApp-এ নিজের কাছে পাঠিয়ে রাখা যায়।

## APK বানানোর নিয়ম (একবারের কাজ, বিনামূল্যে)

APK ফাইল GitHub নিজেই বানিয়ে দেবে। কম্পিউটার থেকে করা সহজ।

1. [github.com](https://github.com) এ অ্যাকাউন্ট খুলুন (বা লগইন করুন)।
2. উপরের ডানে **＋ → New repository**। নাম দিন `case-diary`, **Private** বেছে নিন, **Create repository**।
3. নতুন পাতায় **uploading an existing file** লিংকে ক্লিক করুন।
4. এই জিপ ফাইল আনজিপ করুন। ভেতরের **সব ফাইল ও ফোল্ডার** (`www`, `assets`, `scripts`, `.github`, `package.json`, `package-lock.json`, `capacitor.config.json`, `.gitignore`) টেনে এনে ছেড়ে দিন, তারপর **Commit changes**।
   - `.github` ফোল্ডারটি লুকানো থাকতে পারে। Windows-এ File Explorer-এ *View → Hidden items* চালু করুন; Mac-এ `Cmd + Shift + .` চাপুন।
5. উপরের **Actions** ট্যাবে যান। "APK তৈরি করুন" নামে কাজ চলছে দেখবেন। ৫–১০ মিনিট পর সবুজ টিক আসবে।
   - নিজে থেকে না চললে: Actions → বাঁ দিকে **APK তৈরি করুন** → **Run workflow**।
6. সবুজ টিকওয়ালা কাজটিতে ক্লিক করুন। একদম নিচে **Artifacts** এর নিচে `case-diary-apk` ডাউনলোড করুন। আনজিপ করলে `app-debug.apk` পাবেন।
7. ফাইলটি ফোনে পাঠান (Gmail, WhatsApp বা USB দিয়ে), খুলে ইনস্টল করুন।
   - "অজানা উৎস থেকে ইনস্টল" এর অনুমতি চাইলে দিন।
   - Play Protect সতর্ক করলে **Install anyway** দিন (অ্যাপটি আপনার নিজের বানানো, Play Store-এ নেই)।
8. প্রথমবার অ্যাপ খুললে নোটিফিকেশনের অনুমতিতে **Allow** দিন। তারপর **আরও → পরীক্ষামূলক নোটিফিকেশন** চেপে দেখে নিন ঠিকমতো আসছে কিনা।

## জরুরি পরামর্শ

- **ব্যাকআপ নিয়মিত নিন** (সপ্তাহে একবার)। অ্যাপ মুছে ফেললে বা ফোন হারালে ব্যাকআপ ছাড়া তথ্য ফেরত আসবে না। নতুন ফোনে অ্যাপ ইনস্টল করে **আরও → ব্যাকআপ থেকে ফেরান** দিলেই সব ফিরে আসবে।
- ফোনের ব্যাটারি সেভার অ্যাপটিকে বন্ধ করে দিলে রিমাইন্ডার দেরিতে আসতে পারে। Xiaomi/Oppo/Vivo/Realme ফোনে *সেটিংস → অ্যাপ → কেস ডায়েরি → ব্যাটারি → No restrictions* এবং *Autostart চালু* করে দিন।
- মামলার তথ্য বদলালে (যেমন পরবর্তী তারিখ) **মামলার পাতা → ফলাফল লিখুন** ব্যবহার করুন; এতে ইতিহাসও জমা থাকে আর পরবর্তী তারিখও নিজে থেকে বদলে যায়।

## কোড বদলাতে চাইলে

অ্যাপের পুরো কোড `www/` ফোল্ডারে (`index.html`, `app.css`, `app.js`)। বদলে GitHub-এ আবার আপলোড করলে নতুন APK তৈরি হবে।
